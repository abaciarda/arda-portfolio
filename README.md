# Arda Abacı — Portfolio

Kendi projelerimi sergilediğim ve geliştirme sürecimi paylaştığım kişisel web sitesi.

Modern web teknolojileriyle (Next.js, React, Tailwind) performanslı ve temiz bir kullanıcı deneyimi oluşturmayı hedefledim. 
Zamanla yeni projeler ve içeriklerle genişletmeye devam ediyorum.

🔗 Canlı versiyon: https://ardaabaci.com

## Run locally

```bash
npm install
npm run dev
```

## Content management

Sanity Studio runs separately from the Next.js website. Start it with `npm run studio:dev` after installing its dependencies with `npm install --prefix studio`.

See [Sanity setup](docs/sanity-setup.md) for content import, editing, Studio hosting, and Cloudflare configuration.
